# 4ummah-landing

The marketing site for 4Ummah. Static HTML, CSS and a little JavaScript, served
by GitHub Pages. No build step, no dependencies.

This is **not** the product. The application lives in a separate repository.

## Files

```
index.html    the page
styles.css    palette and type match the product, so the two feel like one thing
main.js       scroll reveal and the footer year, both optional
.nojekyll     stops GitHub Pages running the content through Jekyll
```

## Editing it

Open `index.html` in a browser. That is the whole workflow. Any change is live
on the next push.

## Deploying

Settings, Pages, deploy from the `main` branch root. Every push to `main` is a
deploy.

## Content

Deliberately vague. It says what is being built and how to make contact, with no
invented numbers, no fake testimonials and no launch date. Everything on the
page is either true today or clearly marked as later.
